# 🎯 ScoutCore

**ScoutCore** — це автоматизована асинхронна система агрегації, ETL-обробки та фільтрації вакансій для Python-розробників із популярних українських платформ (DOU, Djinni). Проєкт побудований на базі мікросервісної архітектури, повністю контейнеризований за допомогою Docker та оптимізований під швидкий пошук цільових пропозицій для розробників початкового рівня.

---

## ⚖️ Compliance & Ethical Scraping (Політика збору даних)

Цей проєкт створено виключно в **навчальних та демонстраційних цілях** (Educational & Non-Commercial Project). Розробка велася із суворим дотриманням етичних норм веб-скрапінгу та аналізу відкритих джерел:

* **Повна відповідність robots.txt:**
  * **DOU.ua:** Парсер взаємодіє виключно з розділом `/vacancies/`, який є повністю відкритим для загальних пошукових ботів та індексації. Системні зони (авторизація, адмінка, трекери) залишаються недоторканими.
  * **Djinni.co:** Система взаємодіє виключно з офіційною асинхронною RSS-стрічкою сайту (`/jobs/rss/`), яка інфраструктурно виділена для читання агрегаторами. Проєкт суворо дотримується заборони на роботу з базою кандидатів (`Disallow: /developers`) — дані розробників **взагалі не збираються і не аналізуються**.
* **Rate Limiting & Повага до серверів:** Система не здійснює агресивних і частих HTTP-запитів, які могли б навантажити інфраструктуру сайтів або спровокувати захист Cloudflare. Завдяки планувальнику задач **Celery Beat**, опитування стрічок відбувається у фоновому режимі з великими інтервалами (раз на 4–8 годин), що імітує природну поведінку користувача.
* **No PII (Захист персональних даних):** Проєкт збирає та зберігає виключно загальнодоступну публічну інформацію про вакансії компаній. Жодні персональні дані (Personally Identifiable Information) чи конфіденційні записи не збираються, не обробляються і не зберігаються в базі даних додатка.

## 🚀 Основні можливості (Features)

* **Асинхронний ETL-пайплайн:** Збір, валідація та очищення даних відбуваються у фоновому режимі у Celery-воркерах за допомогою брокера повідомлень Redis.
* **Глибока ETL-фільтрація за стоп-словами:** Система автоматично відсікає нерелевантні ніші (C++, DevOps, QA/AQA) та пропозиції високих рівнів (Middle+/Senior/Lead), аналізуючи заголовки та вимоги до досвіду в описах вакансій.
* **Автоматична ротація даних (Data Retention):** Нічний клінінг-воркер автоматично видаляє з бази PostgreSQL записи, старіші за 30 днів (TTL-політика), підтримуючи базу в актуальному та швидкому стані.
* **Інтерактивний Telegram-бот:** Працює як приватний пульт керування (реалізовано Whitelisting за конкретним Telegram Chat ID). Дозволяє адміну запускати парсери в один клік, переглядати системні звіти терміналу та читати останні вакансії прямо в месенджері.
* **Сучасний Web-дашборд на Django:** Веб-інтерфейс із використанням Bootstrap 5, що включає:
  * Швидкі фільтри за джерелами (Всі / DOU / Djinni).
  * Динамічний пошук за ключовими словами по всій базі даних через Django ORM.
  * Пагінацію (розбиття списку на сторінки) для оптимізації UX.
  * Кастомні теги-фільтри (`Template Filters`) для динамічного підсвічування ключових навичок (Python, Django, Docker тощо) у тексті карток.
  * Панель керування парсерами (Celery тригери) та швидкий перехід до кастомізованої Django-адмінки (CRM).

## 🛠 Технологічний стек (Tech Stack)

* **Backend:** Python, Django, Django REST Framework
* **Asynchronous Execution:** Celery, Celery Beat
* **Message Broker & Cache:** Redis
* **Database:** PostgreSQL
* **HTML Parsing:** BeautifulSoup4, XML ElementTree
* **UI/UX:** HTML5, Bootstrap 5, Telebot (pyTelegramBotAPI)
* **DevOps & Security:** Docker, Docker Compose, Python-Environ
